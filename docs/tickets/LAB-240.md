# LAB-240: CSV reports break in spreadsheet tools when a field contains a quote

**Type:** bug · **Component:** labio · **Reporter:** quality management

## Problem

A unit name with a double quote (for example `mg/"dL", corr` from a customer configuration)
makes the `REPORT` CSV unreadable in spreadsheet tools: the line is split into the wrong
columns.

## Request

- `lab::io::csv_escape` follows RFC 4180: a field that contains a comma, a double quote, CR or
  LF is enclosed in double quotes, and every double quote inside is doubled.
- `src/labio/src/csv_report.cpp` gets GoogleTest tests (today it has none): `csv_escape`,
  `write_measurements_csv` and `write_assay_summary_csv`, including an empty input.

## Acceptance criteria

- Tests first; they fail on the current code for the right reason.
- The behaviour of `write_assay_summary_csv` does not change. If you find something in it
  that looks wrong, write it into the merge request description as a question.
- `python scripts/check_all.py debug tidy` passes.
