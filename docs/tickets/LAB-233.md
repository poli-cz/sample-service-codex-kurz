# LAB-233: STATUS should show free capacity

**Type:** feature · **Component:** apps/sample-service · **Reporter:** lab operations

## Problem

Before a batch of samples arrives, the operators want to know how much room is left. Today
`STATUS` prints the queue counts per priority and the rack contents, but neither the queue
capacity nor the number of free rack positions.

## Request

Add two fields to the `status` event:

- `queue_free`: how many more samples the queue accepts (capacity minus waiting samples),
- `rack_free`: how many rack positions are empty.

Example: `{"event":"status", ..., "queue_free":47, "rack_free":1}`
