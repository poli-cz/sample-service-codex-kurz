# LAB-242: Evaluate control records with the Westgard rules

**Type:** feature · **Component:** apps/sample-service, labio · **Reporter:** quality management
**Depends on:** LAB-201 (`lab::qc::evaluate_westgard`)

## Problem

The analyzer writes control records `C|pos|lot|assay|signal|flags|timestamp` into its log.
Quality management wants to check a control lot from such a log without a spreadsheet.

## Request

New command `QC <lot> <assay> <target-mean> <target-sd> <file>`:

1. Read the analyzer lines from `<file>`. Use only control records (`C|...`) of the given lot
   and assay, in file order. Lines that do not parse, result records and records of other
   lots or assays are ignored.
2. Control records of that lot and assay with the instrument flag `ERR` are not evaluated;
   count them as `skipped`.
3. Convert each signal to a concentration with the calibration curve of the assay from the
   service configuration, the same way results are converted.
4. Evaluate the concentrations with `lab::qc::evaluate_westgard` (target mean and SD are in
   concentration units).

Output, one JSON object per line:

```
{"event":"qc_violation","lot":"QC-GLU-L1-2611","assay":"GLU","rule":"2-2s","index":9,"value":5.98}
...
{"event":"qc","lot":"QC-GLU-L1-2611","assay":"GLU","values":10,"skipped":1,"violations":5,"status":"rejected"}
```

- `index` counts the evaluated values from 0, `value` is the concentration.
- `status` is `rejected` when any rule other than `1-2s` fired, `warning` when only `1-2s`
  fired, `accepted` otherwise.
- Errors (`{"event":"error","message":...}`): wrong number of arguments
  (`usage: QC <lot> <assay> <target-mean> <target-sd> <file>`), unknown assay, a target that is
  not a number, target SD <= 0, a file that cannot be read.

`examples/qc-glu-lot.txt` is a log of ten mornings; `QC QC-GLU-L1-2611 GLU 5.5 0.2
examples/qc-glu-lot.txt` must end with status `rejected`.

## Acceptance criteria

- GoogleTest tests for all three statuses, the skipped `ERR` record and every error.
- README command table updated.
- `python scripts/check_all.py debug asan tidy` passes.
